# extreme-timer
Test your internal clock with Extreme Timer! Your goal is simple yet thrilling: stop the timer as close to the target time as possible. Play solo, battle a smart AI, or challenge a friend in local 2-player mode. Toggle decimal precision (e.g., 2.3s) for ultimate control. Use the spacebar for split-second accuracy. Can you hit the exact mark?
Check out the live demo here: [Live Demo](https://shainibenjelloun-web.github.io/extreme-timer/)
